# Course Outline: Next.js 15 Foundations ⚡

Accelerate your server-side rendering workflow by completing this 4-part module sequence.

## 🧭 Modules Timeline

### 1. Routing Mechanics
* File-system routing layouts (`app/page.js` vs `app/about/page.js`).
* Configuring nested routes and dynamic slugs (`[id]/page.js`).
* Linking contexts natively using the `<Link>` element wrapper.

### 2. Data Fetching & Core Architectures
* Server Components vs Client Components (`"use client"` directive placement).
* Fetch strategies: Static rendering vs Dynamic server-side execution patterns.
* Handling loading indicators gracefully using a localized `loading.js` block.
