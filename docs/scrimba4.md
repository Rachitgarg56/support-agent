# Challenge: Solo Project — Digital Business Card

It is time to test your skills! You will build a React-based personal profile block completely from scratch. 

## 📋 Requirements
* [ ] Create two distinct component subfolders: `components/Info.js` and `components/Footer.js`.
* [ ] The **Info** component must render a profile picture, name, role title, and interactive link anchors.
* [ ] Implement high-contrast color values matching the Figma layout specs.
* [ ] Use font icons or localized svg files for your social anchor parameters.

> 🚨 **Strict Rule:** Do not modify the target metadata strings inside `index.html`. All UI rendering loops must instantiate directly from `App.js`.
