# Scrimba Editor Shortcuts (Windows) 🪟

Maximize your workflow efficiency inside the interactive code scrims using these built-in hotkeys.

| Action | Shortcut Combo |
| :--- | :--- |
| **Toggle Sidebar** | `Ctrl + B` |
| **Preview Code/Run** | `Ctrl + L` or `Shift + Enter` |
| **Open Mini-Console** | `Ctrl + \`` |
| **Format Document (Prettier)** | `Alt + Shift + F` |
| **Jump 10s Backward** | `Ctrl + Left Arrow` |
| **Jump 45s Forward** | `Ctrl + Right Arrow` |

> 💡 **Tip:** If the keyboard focus is stuck inside the running browser preview frame, press `Esc` to snap focus back onto the line cursor of the code panel.
