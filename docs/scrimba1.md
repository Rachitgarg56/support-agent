# Scrimba - Learn React For Free 🚀

Welcome to the starter files for the **Scrimba Learn React** course challenges! Here, you can find the boilerplate assets and task criteria for all modules.

## 📂 Project Navigation

* `01-static-page/` — Building a basic digital business card.
* `02-data-driven/` — Mapping components to arrays (Airbnb clone).
* `03-state-management/` — State, Effects, and API interaction (Meme generator).

## 🛠️ How to use these files

1. Open any module folder in your workspace.
2. Follow the commented guidelines inside the `index.js` or `App.js` files.
3. If you get stuck, click the **"Show Hint"** or **"Reveal Solution"** screen overlay buttons inside the interactive scrim player.

For support, please visit our active community on [Discord](https://scrimba.com/discord). Happy coding!
